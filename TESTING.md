# Проверки на реальном Android 16 / Nothing OS

Этот список — сценарии для устройства, не утверждение, что они выполнены.

- Установка APK, запуск без сети; отсутствие запросов регистрации.
- Разрешение общей памяти, папки Download/Documents; отказ в разрешении; выбор read-only SAF.
- Выбор вложенной папки SAF, создание папки в ней, создание файлов при вставке; переименование, полный отзыв доступа.
- USB: выбор тома, копия на/с USB, удаление в корзину, отключение USB посреди операции, восстановление в память телефона.
- Несколько файлов и вложенных папок; копия/перемещение >4 ГБ на поддерживающий это том; почти заполненная память.
- Одинаковые имена, разные регистры, длинные имена, папка в саму себя, один путь одновременно через SAF и общую память.
- Остановка приложения и отмена задачи при копировании; при проверке хеша; при удалении исходной папки. Проверить целую резервную копию, маркировку операции и отсутствие автоматического повторного удаления после запуска.
- Корзина: исходная папка исчезла, доступ отозван, файл с тем же именем уже существует; восстановление в другую папку; отдельное подтверждение необратимого удаления.
- ZIP: кириллица/пустые папки/дубликаты имён, испорченная CRC, ../, абсолютные пути, повторяющиеся записи, заполнение диска. Никаких изменений существующих файлов назначения.
- 10 000+ файлов: список/сетка, поиск по подпапкам, отмена поиска, сортировка, отзыв доступа к вложенной папке.
- Изображение большого размера/повреждённое; PDF 1000 страниц/с паролем; текст >1 МБ; аудио/видео с неподдерживаемым кодеком; поворот экрана и уход в фон.
- Share/Open in: одно и несколько файлов, URI права в стороннем приложении; приём SEND/SEND_MULTIPLE/VIEW; временный URI после завершения исходной Activity.
- Светлая/тёмная тема, увеличенный шрифт, жест назад, системные панели, TalkBack.
- Закрыть и открыть приложение: папка/тема/вид/избранное/история/буфер сохранены. Повторная установка APK с той же подписью сохраняет данные.
