# iFiles · Android

Личный офлайн файловый менеджер на Kotlin + Jetpack Compose. Интерфейс вдохновлён Apple Files: крупные заголовки, «Недавние» / «Обзор», сетка/список, светлая/тёмная тема, меню файла. Используются собственные иконки приложения и стандартный шрифт Android, без копирования закрытых ресурсов Apple.

## Возможности

- Общая пользовательская память через необязательный MANAGE_EXTERNAL_STORAGE; выбранные папки и USB через Storage Access Framework с постоянными разрешениями.
- Создание папок, переименование, множественное выделение, копирование и перемещение файлов и папок. Вставка в любую открытую доступную папку.
- Проверка скопированных файлов SHA-256 перед удалением исходника; потоковые операции с буфером 256 КБ.
- Собственная корзина, восстановление в исходную или другую папку, защита от перезаписи совпадающего имени. «Удалить всё» и множественное выделение с одним подтверждением необратимого удаления.
- Поиск в текущей папке и подпапках; сортировка по имени, размеру, дате, типу; изменение порядка.
- Избранные файлы и папки, отмеченные звездой, отдельно от папок быстрого доступа в «Обзоре»; история 200 последних открытых файлов.
- Свойства, подсчёт размера папок и числа файлов; общий объём и свободное пространство памяти телефона.
- Встроенный просмотр изображений с масштабированием, PDF постранично, текста UTF-8, воспроизведение локального аудио/видео Media3.
- Миниатюры изображений/видео с ограниченным кэшем; ленивые списки и сетки.
- ZIP с папками, извлечение в отдельную новую папку, защита от Zip Slip, перезаписи и повторяющихся путей.
- Системные «Поделиться» и «Открыть с помощью», получение VIEW/SEND/SEND_MULTIPLE.
- Последняя папка, вид, сортировка, тема, избранное и буфер операций сохраняются. Сканирование изменённых локальных файлов обновляет MediaStore.
- Фоновые операции WorkManager, уведомление с отменой; последовательная очередь. Интернет, реклама, аналитика, регистрация отсутствуют.

## Первый запуск

1. Для папок «На этом телефоне» и «Загрузки» нажать **Разрешить доступ** и предоставить системное разрешение управления файлами. Оно необязательно: можно выбрать конкретные папки.
2. **Добавить папку** — закрепить выбранную папку в «Обзоре» через системный диалог. Смонтированные внешние накопители появляются в «Обзоре» автоматически; без ранее выданного доступа при первом открытии потребуется разрешение Android.
3. Нажатие файла — быстрый просмотр. Долгое нажатие — меню. Кнопка `…` — папка, выделение, сортировка, вид, тема.
4. Копировать/переместить → открыть папку назначения → **Вставить**. Корзина находится в «Обзор».
5. При запросе разрешить уведомления, чтобы видеть длительные операции и кнопку отмены.

## Сборка

JDK 17, Android SDK 36, Build Tools 35.0.0 (стандарт AGP), Gradle 8.13, AGP 8.11.1, Kotlin 2.1.20.

Открыть каталог в Android Studio. Либо:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease
```

Уменьшенный установочный APK: `app/build/outputs/apk/release/app-release.apk`. Отладочный: `app/build/outputs/apk/debug/app-debug.apk`. Оба для личного использования подписываются development/debug сертификатом.

GitHub Actions запускает те же проверки при push, PR и вручную; APK доступен в артефакте **iFiles-install-apk**. Отчёты — **verification-reports**. Это сборка для личной установки, не публикация в Google Play.

Приватный архив исходников содержит `signing/debug.keystore` для воспроизводимой подписи установочного APK; файл исключён из git. Не загружать этот файл или целиком приватный ZIP в публичный репозиторий. На GitHub передаются только исходники без ключа.

CI кэширует debug.keystore для обновлений поверх предыдущей установки. Для гарантированно постоянной подписи задать секрет репозитория DEBUG_KEYSTORE_BASE64 из сохранённого файла `signing/debug.keystore` (пароли стандартного Android debug key). Не добавлять ключ в исходники. Потеря ключа потребует переустановки, что уничтожит внутреннюю корзину; сначала восстановить файлы и сохранить пользовательские документы.

## Безопасность и ограничения

- MANAGE_EXTERNAL_STORAGE не даёт root и доступа к приватным данным других приложений, `/Android/data` и `/Android/obb`. SAF также подчиняется ограничениям Android и поставщика документов.
- Корзина хранится **внутри данных iFiles**. Удаление приложения или очистка его данных уничтожают корзину и папку iFiles. Не считать её независимой резервной копией.
- Перед удалением создаётся полная копия, проверяется содержимое и атомарно фиксируется журнал; только затем удаляется исходник. После восстановления резервная копия остаётся до явного удаления из корзины. Незавершённая копия помечается отдельно; из неё нельзя запускать обычное восстановление.
- При отмене/обрыве копирования могут остаться неполные файлы назначения. При отмене удаления папки исходная папка может сохраниться частично; полная проверенная копия остаётся в корзине. Дубликаты никогда не заменяются молча.
- SAF не предоставляет универсальной транзакции или блокировки против другого приложения, меняющего файл в тот же момент. Не редактировать исходные файлы параллельно с перемещением/удалением. Изменения, замеченные при повторной проверке, останавливают удаление; абсолютную атомарность сторонних провайдеров Android гарантировать нельзя.
- WorkManager после аварийного завершения не повторяет начатую операцию автоматически: она отмечается прерванной, чтобы избежать повторного удаления. Проверить назначение и корзину, затем повторить вручную. Самопроизвольного продолжения удаления нет.
- Android ограничивает время фоновых задач/foreground service. Уведомление не отменяет системных лимитов. При системном прерывании применяются описанные правила восстановления.
- Для больших копий/корзины/PDF требуется свободное место. Приложение не загружает большой файл целиком в память. PDF временно копируется в кэш для seekable PdfRenderer; ошибка нехватки места показывается пользователю.
- Быстрый текстовый просмотр ограничен первым 1 МБ UTF-8. Другие кодировки, Office-документы, защищённый PDF и неподдерживаемые кодеки — через внешнее приложение. Изображения отображаются с уменьшением до безопасного разрешения; это просмотр, не редактор.
- Глубина файловых операций ограничена 128 уровнями; ZIP — 100 000 записей/512 ГБ распакованных данных; поиск — до 10 000 совпадений, при превышении показывает необходимость уточнить запрос. Символические ссылки не копируются; операция над содержащей их локальной папкой отменяется.
- Список папки загружается вне UI-потока, отображение ленивое. Фактическое время чтения большого SAF-каталога зависит от USB/провайдера. Заявлений о проверке производительности на Nothing Phone (4a) нет без реального устройства.

## Код

`Storage.kt` — SAF/файлы, проверенные операции и журнал корзины. `Archives.kt` — ZIP. `Operations.kt` — WorkManager. `FilesViewModel.kt` — состояние и поиск. `Preview.kt` — просмотр/миниатюры. `MainActivity.kt` — Compose UI и Intents.

Состояние проверки и известные ограничения текущего результата — `VALIDATION.md`.
